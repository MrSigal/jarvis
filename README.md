# J.A.R.V.I.S – הוראות

## התקנה (פעם אחת)
1. חלץ את הקובץ: לחיצה ימנית על **JARVIS.zip**, ואז **"חלץ הכל"**.
2. בתיקייה שנפתחה, לחץ פעמיים על **install**. אם קופץ מסך כחול, לחץ על "More info" ואז על "Run anyway".
3. חכה שיופיע **DONE!**. על שולחן העבודה יופיע אייקון בשם **JARVIS**.

## הפעלה
לחיצה כפולה על האייקון **JARVIS** שעל שולחן העבודה.

## בפעם הראשונה – מדביקים מפתחות
ייפתח חלון **SYSTEM CONFIGURATION**:
- **CLAUDE API KEY** – המוח, חובה. בלעדיו ג'רוויס מבין רק פקודות פשוטות.
  נכנסים ל־console.anthropic.com ← נרשמים ← Billing (מוסיפים כמה דולרים) ← API Keys ← Create Key ← מעתיקים ומדביקים.
- לוחצים על **SAVE & CONNECT**.

אפשר לחזור להגדרות בכל רגע דרך גלגל השיניים שבפינה.

## שימוש
אומרים **"Hey Jarvis"**, מחכים לצפצוף ומדברים באנגלית. אפשר גם ללחוץ על העיגול באמצע, על הכפתור **TALK**, או להקליד בשורה למטה.

**דוגמאות:** "Open Spotify", "Close Chrome", "Play Imagine Dragons on YouTube", "What's the weather tomorrow?", "Set a timer for 5 minutes", "Volume to 40", "Take a screenshot", "Open my downloads folder".

לפני פעולות מסוכנות, כמו כיבוי או הפעלה מחדש של המחשב, ג'רוויס תמיד שואל קודם ומחכה ל־"Yes".

## אם משהו לא עובד
לחץ פעמיים על **troubleshoot**, צלם את החלון ושלח לי.

## עדכונים
ג'רוויס בודק לבד אם יש עדכון בכל פעם שהוא נפתח. כשיש עדכון, הכפתור **UPDATE** שלמעלה מתחיל להבהב בכתום.
לוחצים עליו, או אומרים לג'רוויס **"Update yourself"**, והוא מוריד את העדכון ומפעיל את עצמו מחדש. לא צריך להוריד שום קובץ.
