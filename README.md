# J.A.R.V.I.S – עוזר אישי למחשב

## התקנה
1. מורידים את **JARVIS-Setup.exe** מהגרסה האחרונה: https://github.com/MrSigal/jarvis/releases/latest
2. פותחים אותו. אם קופץ מסך כחול "Windows protected your PC", לוחצים על **More info** ואז על **Run anyway**.
3. בסוף ההתקנה ג'רוויס נפתח לבד. הוא מופיע בתפריט התחל ועל שולחן העבודה.

לא צריך Python ולא צריך הרשאות מנהל. אם כבר השתמשת בגרסה הקודמת, ג'רוויס מציע לעבור לתוכנה בכפתור **עדכון**, וההגדרות שלך עוברות איתו.

## בפעם הראשונה
בהגדרות (גלגל השיניים):
- **המוח:** בוחרים Groq, שהוא חינמי, ומדביקים מפתח מ־https://console.groq.com/keys. אפשר גם לבחור Claude, שעולה כסף.
- **קול:** אברי והילה חינמיים ומהירים. Gemini של גוגל נשמע הכי טבעי ודורש מפתח חינמי מ־https://aistudio.google.com/apikey.
- **אייפון, לא חובה:** סורקים את הקוד בהגדרות ומוסיפים למסך הבית. החיבור מוצפן, ואפשר לנעול את האפליקציה עם Face ID.

## שימוש
אומרים **"היי ג'רוויס"**, מחכים לצפצוף ומדברים בעברית. אפשר גם ללחוץ על העיגול, על **דבר**, או להקליד.

**דוגמאות:**
- "תפתח ספוטיפיי", "תסגור את כרום"
- "מה מזג האוויר מחר?", "מה החדשות?"
- "תזכיר לי בשש לקחת את הכביסה"
- "שים טיימר לעשר דקות", "תוריד את הווליום ל־30"

ג'רוויס פועל רק כשמבקשים ממנו. לפני דברים מסוכנים, כמו כיבוי המחשב, הוא שואל קודם.

## עדכונים
כשיש גרסה חדשה, הכפתור **עדכון** למעלה מהבהב בכתום. לוחצים עליו או אומרים "תתעדכן". ג'רוויס מתקין את העדכון ונפתח מחדש.

## הסרה
הגדרות Windows ← אפליקציות ← J.A.R.V.I.S ← הסר.

## פרטיות ואבטחה
- המפתחות והסיסמאות נשמרים מוצפנים במחשב (Windows DPAPI). רק המשתמש שלך ב־Windows יכול לפתוח אותם.
- החיבור בין האייפון למחשב מוצפן מקצה לקצה (AES-256-GCM). בלי קוד החיבור אי אפשר לקרוא או לשלוח פקודות, וקוד חדש מנתק טלפונים ישנים.
- במייל ג'רוויס רק קורא, לא מוחק ולא שולח.

## חדש בגרסה 4.8
- **"בוקר טוב"**: תדריך קולי עם מזג אוויר, תזכורות להיום ומיילים חשובים.
- **שגרות**: פקודה אחת שעושה כמה דברים ("מצב עבודה", "לילה טוב"). עורכים בהגדרות או מבקשים מג'רוויס.
- **שליטה מהאייפון** (כפתור 🎛 באפליקציה): צילום של מסך המחשב, נעילה, עוצמה, שינה, כיבוי וביטול כיבוי.
- **קבצים בין המחשב לאייפון**: "תשלח לי לטלפון את הקובץ האחרון שהורדתי", ושליחת קבצים מהטלפון לתיקייה הורדות ← Jarvis. הכול מוצפן.
