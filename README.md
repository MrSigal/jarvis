# J.A.R.V.I.S – הוראות

## התקנה (פעם אחת)
1. חלץ את הקובץ: לחיצה ימנית על **JARVIS.zip**, ואז **"חלץ הכל"**.
2. בתיקייה שנפתחה, לחץ פעמיים על **install**. אם קופץ מסך כחול, לחץ על "More info" ואז על "Run anyway".
3. חכה שיופיע **DONE!**. על שולחן העבודה יופיע אייקון בשם **JARVIS**.

## הפעלה
לחיצה כפולה על האייקון **JARVIS** שעל שולחן העבודה.

## בפעם הראשונה – מדביקים מפתחות
ייפתח חלון **הגדרות מערכת**:
- **מפתח Claude** – המוח, חובה. בלעדיו ג'רוויס מבין רק פקודות פשוטות.
  נכנסים ל־console.anthropic.com ← נרשמים ← Billing (מוסיפים כמה דולרים) ← API Keys ← Create Key ← מעתיקים ומדביקים.
- לוחצים על **שמור והתחבר**.

אפשר לחזור להגדרות בכל רגע דרך גלגל השיניים שבפינה.

## שימוש
אומרים **"היי ג'רוויס"**, מחכים לצפצוף ומדברים בעברית. אפשר גם ללחוץ על העיגול באמצע, על **דבר**, או להקליד בשורה למטה.
ג'רוויס מבין רק עברית. לדיבור בשפות אחרות הוא לא מגיב.

**דוגמאות:** "תפתח ספוטיפיי", "תסגור את כרום", "תנגן ביוטיוב שיר של עומר אדם", "מה מזג האוויר מחר?", "שים טיימר ל־5 דקות", "תוריד את הווליום ל־40", "תצלם את המסך", "תפתח את תיקיית ההורדות".

לפני פעולות מסוכנות, כמו כיבוי המחשב, ג'רוויס תמיד שואל קודם ומחכה ל"כן".

## אם משהו לא עובד
לחץ פעמיים על **troubleshoot**, צלם את החלון ושלח לי.

## עדכונים
ג'רוויס בודק לבד אם יש עדכון בכל פעם שהוא נפתח. כשיש עדכון, הכפתור **עדכון** שלמעלה מתחיל להבהב בכתום.
לוחצים עליו, או אומרים לג'רוויס **"תתעדכן"**, והוא מוריד את העדכון ומפעיל את עצמו מחדש. לא צריך להוריד שום קובץ.
